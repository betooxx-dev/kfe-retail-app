# Prosur 2026 - KFE Retail App

Aplicación de gestión y punto de venta desarrollada para Prosur. El proyecto está dividido en dos partes principales: Backend (API) y Frontend (Cliente Web).

## Tecnologías Principales Utilizadas

- **Frontend:** Next.js, React, TailwindCSS.
- **Backend:** NestJS, TypeScript, TypeORM, PostgreSQL.
